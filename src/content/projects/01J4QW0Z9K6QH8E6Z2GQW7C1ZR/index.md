# Neutrino CMS - Sistema di Gestione Contenuti

## Panoramica del Progetto

**Neutrino CMS** è un sistema di content management moderno e scalabile progettato per gestire contenuti web in modo efficiente e professionale. Il sistema è stato sviluppato utilizzando le tecnologie più moderne e segue le best practice dell'industria.

## Caratteristiche Principali

### 🚀 **Sistema ULID Avanzato**
- Identificatori univoci di 26 caratteri ordinabili cronologicamente
- Gestione completa per Posts, Pages e Projects
- Struttura file organizzata e scalabile

### 🌍 **Supporto Multi-Lingua**
- Sistema di traduzione integrato
- Supporto per italiano e inglese
- Estensibile per altre lingue

### 📝 **Gestione Contenuti Completa**
- **Posts**: Articoli e notizie con sistema di tag
- **Pages**: Pagine statiche con ordinamento menu
- **Projects**: Portfolio progetti con metadati avanzati

### 🎨 **Interfaccia Admin Moderna**
- Dashboard intuitiva e responsive
- Editor markdown integrato
- Gestione completa dei metadati

## Tecnologie Utilizzate

### Backend
- **Node.js**: Runtime JavaScript lato server
- **Fastify**: Framework web veloce e moderno
- **Nunjucks**: Template engine potente e flessibile

### Frontend
- **HTML5**: Struttura semantica moderna
- **CSS3**: Styling avanzato e responsive
- **JavaScript ES6+**: Logica client-side moderna

### Gestione Contenuti
- **Markdown**: Formato di scrittura pulito e leggibile
- **YAML**: Metadati strutturati e facili da gestire
- **ULID**: Sistema di identificazione univoco

## Architettura del Sistema

### Struttura Directory
```
neutrino-cms/
├── content/           # Contenuti del CMS
│   ├── posts/        # Articoli e notizie
│   ├── pages/        # Pagine statiche
│   └── projects/     # Portfolio progetti
├── templates/         # Template Nunjucks
├── server/           # API e logica server
├── locales/          # File di traduzione
└── schemas/          # Schemi di validazione
```

### API Endpoints
- **Admin**: `/admin/*` - Gestione contenuti
- **Pubblici**: `/*` - Accesso ai contenuti pubblici
- **RESTful**: CRUD completo per tutti i tipi di contenuto
