### Sistema delle abilità
Abbiamo aggiunto un sistema di abilità che vi consente di guadagnare punti esperienza mentre compiete delle attività. Questi punti potranno poi essere spesi in varie abilità che vi conferiranno diversi vantaggi.
La mod nello specifico è la famigerata [XSkills](https://mods.vintagestory.at/show/mod/247) e offre un buon sistema di progresso esperienza.
L'idea è quella di aggiungere degli obiettivi al gioco.
